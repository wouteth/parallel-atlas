# Natural Earth land basemap

`land-110m.geojson` is Natural Earth 1:110m land geometry, downloaded September 14, 2026 from the source repository:

https://raw.githubusercontent.com/nvkelso/natural-earth-vector/master/geojson/ne_110m_land.geojson

Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/

This is a modern reference basemap, not a historical coastline reconstruction. Political boundaries are not drawn. It is bundled so map viewing requires no third-party map service or token.
