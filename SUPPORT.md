# Getting help

Project Timeline is a community project maintained by [@wouteth](https://github.com/wouteth). Help is offered as availability permits, without a guaranteed response time.

| You need                                         | Start here                                                                                                                                                    |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Installation or local setup                      | [README](README.md#run-locally), then search [existing issues](https://github.com/wouteth/project-timeline/issues).                                           |
| A bug fix                                        | Open a [bug report](https://github.com/wouteth/project-timeline/issues/new?template=bug_report.md) with reproduction steps.                                   |
| A source, date, attribution, or image correction | Open a [research correction](https://github.com/wouteth/project-timeline/issues/new?template=research_correction.md) with the entry ID and supporting source. |
| A new capability                                 | Read the [roadmap](ROADMAP.md), then open a [feature proposal](https://github.com/wouteth/project-timeline/issues/new?template=feature_request.md).           |
| Help contributing                                | [CONTRIBUTING.md](CONTRIBUTING.md) and the [content guide](docs/content-guide.md).                                                                            |
| To report a vulnerability                        | The private reporting route in [SECURITY.md](SECURITY.md).                                                                                                    |
| To report misconduct                             | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md#reporting-and-moderation).                                                                                            |

If existing documentation does not answer a setup question, open a [general issue](https://github.com/wouteth/project-timeline/issues/new). Include your Node/pnpm versions, operating system, command, and sanitized error output. For interface problems, include the browser, viewport size, and route. Never include secrets, account cookies, or a database containing personal data.

Research requests are easier to evaluate with a specific passage, artifact record, publication, or timestamp. Project Timeline does not provide personalized historical authentication or a comprehensive review of every tradition it indexes.
